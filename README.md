# APNG Studio & Converter 

Una aplicación web desarrollada con Python y Streamlit para convertir secuencias de imágenes PNG o videos en formato MP4 a archivos gráficos animados **APNG**.

## Características
- **Soporte dual:** Convierte secuencias de fotos PNG o videos MP4.
- **Control de velocidad:** Configuración personalizable de fotogramas por segundo (FPS).
- **Barra de estado:** Progreso de extracción y renderizado en tiempo real.
- **Sin instalaciones necesarias:** Funciona directamente desde el navegador.

## Tecnologías utilizadas
- Python 3.10+
- [Streamlit](https://streamlit.io/)
- [OpenCV](https://opencv.org/)
- [apng](https://pypi.org/project/apng/)
